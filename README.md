## ✦ 关于 Noi Video

**Noi Video** 是一款 Windows 桌面工具，集合视频提取、网盘分享解析和下载管理。粘贴链接后查看内容信息、选择保存方式，让收集与整理变得更简单。

## ♡ 功能介绍

| | 功能 | 你可以做什么 |
| :---: | :--- | :--- |
| 🎬 | **视频提取** | 粘贴分享文案或链接，解析视频信息，查看封面、标题、作者、时长与画质。 |
| ✨ | **画质与保存** | 选择可用画质、文件名和保存目录；下载后打开所在文件夹。 |
| 🗂️ | **批量处理** | 添加多条链接并选择导出目录，在队列中查看各项处理状态。 |
| ☁️ | **网盘解析** | 解析分享链接、浏览文件和文件夹，将可下载内容加入队列。部分平台需要登录或验证。 |
| 🎵 | **音视频选择** | B 站视频可选择音视频合并、仅音频、仅视频或分别保存。 |
| 🖼️ | **图集下载** | 对支持的图文作品，可选择下载单张或全部图片。 |
| 📥 | **下载管理** | 查看下载进度，并根据任务状态进行暂停、继续或取消操作。 |

## 🌸 支持平台

视频提取涵盖 **抖音、哔哩哔哩、YouTube、X / Twitter** 等平台；网盘工具覆盖 **夸克、UC、百度、迅雷、123、115、139、光鸭及蓝奏云**等分享类型。

> [!NOTE]
> 能否解析和下载取决于作品或分享的可访问性、平台限制及账号状态。私密、付费、地区限制或受保护内容可能无法处理；部分网盘功能需要登录或完成官方验证。

## ↓ 下载使用

前往 [Releases](https://github.com/zxc19800zxc/Noi-Video/releases/tag/v2.1.7-test) 下载 **Noi Video Extractor 2.1.7 测试版**。第一次使用可以先看这份 [详细使用说明](使用说明.md)。

这次整理了默认保存位置：登录后会在桌面创建 `NoiVideo` 文件夹；没有选择其他目录时，提取的视频和图片会放在这里。单个和批量提取都能终止当前任务，下载进度也会区分传输与文件处理阶段。

1. 打开 Noi Video，按提示完成登录。
2. 粘贴视频或网盘分享链接，开始解析。
3. 查看内容并选择保存方式和位置。
4. 在下载任务中查看进度，完成后打开文件所在位置。
